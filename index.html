Portal Monumenta

Acesso restrito a RH e liderança sênior. Cole abaixo seu token de acesso pessoal do GitHub (com permissão apenas no repositório de dados privado) para entrar.

Não sei como gerar meu token
  1. Acesse github.com → foto de perfil → Settings.
  2. No menu esquerdo, role até "Developer settings".
  3. Clique em "Personal access tokens" → "Fine-grained tokens" → "Generate new token".
  4. Em "Resource owner" escolha o dono do repositório. Em "Repository access" escolha "Only select repositories" e marque monumentabaserh.
  5. Em "Permissions" → "Repository permissions" → "Contents" → selecione "Read and write".
  6. Gere o token e cole aqui. Guarde-o — o GitHub só mostra uma vez.
